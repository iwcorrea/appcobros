# 💰 CobraDiario - Plataforma de Cobro Diario

Aplicación web para gestionar cobros de ruta diaria en Colombia.  
Permite llevar el control de pagos diarios por cliente, con roles de administrador (maestro) y cliente.

**Generado por el ecosistema autónomo de agentes IA (AI-ECOSYSTEM).**

---

## 🚀 Tecnologías

### Backend
- **FastAPI** - Framework web asíncrono
- **SQLAlchemy** - ORM para base de datos
- **SQLite** - Base de datos ligera
- **JWT** - Autenticación segura
- **Pydantic** - Validación de datos

### Frontend
- **React 18** - Biblioteca UI
- **Tailwind CSS** - Estilos utilitarios
- **React Router** - Navegación
- **Axios** - Cliente HTTP
